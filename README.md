**MaterialMind** is a materials informatics project investigating whether explicit crystal-structure representations learned via **Graph Neural Networks (GNNs)** provide complementary predictive power beyond traditional **composition-based tabular descriptors** when predicting a material's **bulk modulus ($K$)**. I chose to do This project to learn more about GNN and it's application. 

---

## 📌 Project Overview & Research Focus

Bulk modulus ($K$) measures a material's resistance to uniform compression. While direct computational evaluation (e.g., DFT) or experimental measurement is costly, machine learning allows rapid screening across vast chemical spaces.

Traditional models use **compositional descriptors** (e.g., Magpie elemental statistics) to predict properties, missing explicit 3D crystal arrangements. **MaterialMind** evaluates whether GNN structural embeddings capture novel, complementary physical signals.
