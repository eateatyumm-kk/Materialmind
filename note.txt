what is feature engineering? 
process of transforming raw data in to data ready for ML. 
typical steps of feature engineering
1. Data cleaning and Parsing -> fix missing data and convert string in to structured data object
2. Feature generation -> create new column/attribute from your existing data
3. Feature selection -> remove the redandant data
4. Data splitting -> break the data into independent and dependent variable
